## Collaboration with Codex

Codex is used as an iterative product and engineering partner across the workspace:

- translate product ideas into small, usable increments;
- implement and refactor the HTML, CSS, and JavaScript;
- review UX, responsive behavior, accessibility, and visual consistency;
- diagnose regressions and validate fixes with syntax checks and focused smoke tests;
- keep changes organized with semantic commits and repository pushes when requested;
- maintain project documentation as the workspace evolves.

Each project README contains more specific context about its purpose, stack, current capabilities, and collaboration history.

## Documentation workflow

At the end of each development day, update:

1. this root README with project-level changes, new projects, stack changes, and current status;
2. the README inside every project touched that day with its latest features, decisions, and usage notes;
3. the relevant semantic commit message so the repository history remains easy to understand.

This keeps the repository useful as both a codebase and a living record of the work.
