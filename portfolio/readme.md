# Portfolio

## Purpose

This is a personal portfolio landing page for Thiago Fontanella, presenting:

- senior full-stack engineering experience;
- selected work such as CoPickr and AgregadorFCB;
- product thinking, frontend craft, and AI/automation interests;
- a concise professional timeline and contact call to action.

## Stack

- HTML5
- CSS3
- vanilla JavaScript
- Google Fonts: Manrope and DM Mono
- no backend, build step, or framework

Open index.html directly in a browser.

## Collaboration with Codex

Codex was used as a design and implementation partner for the landing page: shaping the visual direction, structuring the sections, writing the semantic HTML, creating the dark editorial visual system and CSS artwork for the project cards, adding responsive behavior, and implementing smooth in-page navigation.

The page is intentionally dependency-light so it can remain easy to open, review, and evolve locally.

## Current status

The portfolio is a static first version. Future iterations may connect the project cards to live case studies, replace placeholder contact details, and add a deployment workflow.
