# Portfolio

## Purpose

This is a personal portfolio landing page for Thiago Fontanella, presenting:

- senior full-stack engineering experience;
- selected work such as CoPickr, AgregadorFCB, Personal OS, and Steam Log;
- product thinking, frontend craft, and AI/automation interests;
- a concise professional timeline and contact call to action.

## Stack

- HTML5
- CSS3
- vanilla JavaScript
- Google Fonts: Manrope and DM Mono
- no backend, build step, or framework

Open index.html directly in a browser.

## Collaboration with Codex

Codex was used as a design and implementation partner for the landing page: shaping the visual direction, structuring the sections, writing the semantic HTML, creating the dark editorial visual system and CSS artwork for the project cards, adding responsive behavior, and implementing smooth in-page navigation.

The page is intentionally dependency-light so it can remain easy to open, review, and evolve locally. The two local product cards link to `../personal-os/index.html` and `../steam-log/index.html` when the repository is opened directly in a browser.

## Project build flags

Each project card includes a visible build-method flag:

- `Feito com IA` marks projects developed in collaboration with Codex as an AI-assisted product and engineering workflow.
- `Feito à mão` marks projects presented as hand-built concepts or work that does not currently have a documented AI-assisted implementation in this workspace.

The flag describes the making process, not whether the product itself contains AI features.

## Current status

The portfolio is a static first version. Future iterations may connect the project cards to live case studies, replace placeholder contact details, and add a deployment workflow.
